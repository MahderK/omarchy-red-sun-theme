# Red Sun

A black-and-red monochrome theme for [Omarchy](https://omarchy.org/), built around famous Ethiopian landmarks as its base.

## Install

```bash
omarchy theme install https://github.com/MahderK/omarchy-red-sun-theme
```

## Includes

- `colors.toml` — palette (terminals, editors, shell, and apps are themed from this)
- `icons.theme` — GTK icon theme
- `shell.lock.toml` — lock screen colors
- `unlock.png` / `preview-unlock.png` — Plymouth boot screen logo and preview
- `preview.png` — desktop preview
- `backgrounds/` — bundled wallpapers
